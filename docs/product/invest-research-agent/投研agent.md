## 1. 产品概述

### 1.1 一句话定位

> 一款面向 C 端个人投资者的**自动化投研监控 AI Agent**：全天候盯盘 + 结构化复盘 + 低风险解读 + 逻辑化预警。**只做投研辅助，不做交易、不荐股、不承诺收益。**

### 1.2 与市面产品的本质区别

本产品核心**不是「问答聊天」**，而是替用户完成每日重复、高频、高耗时的投研监控工作：

| 维度 | 通用 AI 助手 | 传统行情软件 | 本产品 |
| --- | --- | --- | --- |
| 工作方式 | 被动问答 | 被动展示 | **Agent 自动化工作流**（扫描→分析→推送→归档） |
| 数据 | 无实时行情 | 有数据无解读 | 实时数据 + 专属投研规则解读 |
| 输出质量 | 泛化、易幻觉 | 数据堆砌 | 结构化、可溯源、强制校验 |
| 合规 | 无约束 | — | 无荐股、无预测、强制风险提示 |

### 1.3 目标用户

- **核心用户**：A股 / 美股 / 港股个人散户、短线交易者、波段投资者、行业主题投资者（半导体、新能源、消费等细分赛道）
- **用户特征**：有自主交易能力、没时间盯盘、需要系统化投研辅助、拒绝无脑荐股、追求信息高效精准

### 1.4 解决的核心痛点

1. **盯盘成本高** —— 无法全天候盯盘，错过异动、板块轮动、财报信号
2. **信息过载** —— 行情、新闻、研报杂乱，人工筛选耗时
3. **解读不专业** —— 看不懂技术指标、资金流向，通用 AI 解读泛泛且易幻觉
4. **复盘无体系** —— 每日交易、持仓变化无结构化沉淀
5. **预警不精准** —— 传统软件只有价格预警，无「异动+资金+新闻」逻辑共振预警

## 3. 整体架构

四层架构，轻量化落地，**无需自研大模型**，依托成熟 LLM API + 专属规则库构建壁垒。

```
┌─────────────────────────────────────────────┐
│  交互层：移动端/网页看板 · 自选列表 · 复盘日志 ·  │
│         消息推送 · AI 对话窗口                  │
├─────────────────────────────────────────────┤
│  Agent 层：自动扫描 · 异动解读 · 复盘 ·          │
│           预警推送 · 智能问答                    │
├─────────────────────────────────────────────┤
│  规则引擎层（核心壁垒）：监控规则 · 异动判定 ·     │
│           技术指标信号 · 风险筛查 · 情绪评分 ·      │
│           幻觉校验                              │
├─────────────────────────────────────────────┤
│  数据层：行情 · 资金流 · 财经新闻 · 财报摘要 ·     │
│           板块轮动 · 个股公告 · 期权数据（港美股）  │
└─────────────────────────────────────────────┘
```

**Agent 统一工作流**（固定流程，非被动问答）：

> 定时扫描 → 数据清洗 → 规则判定 → AI 结构化生成 → 幻觉校验 → 推送归档

## 4. 核心功能模块（MVP）

### 模块 1：智能自选监控看板（基础底座）

替代传统自选列表，展示的不是价格，而是**风险与机会信号**。

- **多市场**：A股、美股、港股；个股、行业板块、指数
- **动态数据卡片**：实时价格、涨跌幅、成交量、北向/主力资金、近 3 日异动次数、情绪评分
- **期权数据卡片**（仅美股/港股个股）：Put/Call Ratio、隐含波动率（IV）及异动、当日大额期权成交摘要、关键行权价期权墙位置
- **AI 状态标签**：自动标注「强势震荡 / 异动拉升 / 资金流出 / 风险偏高 / 利好催化」
- **技术信号摘要**：每个标的展示当前有效技术信号（如「MA 多头排列」「MACD 顶背离」「缩量回踩 20 日线」），信号分级标识（一级/二级/三级）
- **大盘指数区**：各市场核心指数卡片（涨跌、成交、情绪、资金结构），点击展开**指数级 AI 市场分析**（市场事实→驱动原因→结构解读→风险提示→跟踪建议）
- **市场总览条**：涨跌家数、两市/大市成交、北向/南向资金、赚钱效应、板块轮动热力图（点击跳转板块景气）
- **批量扫描**：每日 9:00、14:00、收盘后自动扫描全部自选，生成监控简报

### 模块 2：板块景气分析引擎（大盘→板块→个股的中间层）

补齐自上而下投研链路的板块层：指数分析回答「市场环境如何」，板块景气回答「资金在哪个方向」，个股解读回答「具体标的怎么了」。三个市场各覆盖主要板块（美股：半导体/互联网软件/金融/消费/医疗/能源等）。

**景气度综合评分（自研复合指标）：**

- 加权维度：动量、资金、情绪、基本面（正向评分）+ **拥挤度（反向指标，>70 代表交易拥挤、短线风险高）**
- 板块卡片墙：评分环 + 等级标签（高景气 / 中性 / 低迷）+ 关键指标摘要 + 龙头标的联动表

**轮动地图（资金 × 动量四象限）：**

| 象限 | 特征 | 含义 |
| --- | --- | --- |
| 主升吸金 | 资金入 · 动量强 | 主线行情核心区，需同步盯拥挤度 |
| 资金承接 | 资金入 · 动量弱 | 左侧布局特征，等动量确认 |
| 冲高兑现 | 资金出 · 动量强 | 高位分歧，注意利好兑现 |
| 弱势失血 | 资金出 · 动量弱 | 规避区，低拥挤度板块具备反向关注价值 |

**输出规则：**

- 景气度/拥挤度等自研复合指标**必须标注计算口径**，杜绝黑盒分数
- AI 板块解读固定四段式：景气事实 → 驱动逻辑 → 轮动位置 → 风险与跟踪
- 传闻类信息强制做「事实 / 传闻分层标注」

### 模块 3：行情异动 AI 解读 Agent（核心主打）

解决「看不懂异动、不知道涨跌原因」。

**触发条件**（用户可自定义阈值）：

| 类型 | 触发规则示例 |
| --- | --- |
| 价格异动 | 日内涨跌超 3% / 5% / 8% |
| 资金异动 | 主力资金大幅净流入/流出、北向异动 |
| 量能异动 | 成交量倍量、缩量突破关键均线 |
| 消息异动 | 突发公告、行业政策、赛道热点新闻 |
| 期权异动（港美股） | 大额/sweep 期权成交、单日成交量较未平仓量（Vol/OI）异常、IV 骤升、Put/Call Ratio 极值 |
| 技术信号异动 | 均线金叉/死叉、MACD 背离、突破关键支撑/压力位、BOLL 带宽收窄后突破（详见模块 5） |

**输出固定五段式结构**（无废话、无幻觉、可溯源）：

1. **异动事实**：客观描述价格/资金/量能数据（绑定来源）
2. **催化原因**：关联当日新闻、政策、板块轮动逻辑
3. **盘面解读**：短期资金情绪、主力行为、趋势强弱
4. **风险提示**：不确定性、利空因素、震荡风险
5. **跟踪建议**：仅观察方向 + 关键压力/支撑位，**无买卖建议**

### 模块 4：期权异动与期权墙分析（港美股专属）

美股/港股期权市场是领先于正股的重要信号源，散户普遍缺乏工具解读。本模块将专业期权数据转译为通俗信号。

**核心分析能力：**

| 分析项 | 说明 | 用户价值 |
| --- | --- | --- |
| 期权异动扫描 | 大额订单、sweep（扫单）、block trade；成交量/未平仓量比（Vol/OI）异常放大 | 捕捉「聪明钱」提前布局信号，往往领先正股异动 |
| 期权墙识别 | Call Wall / Put Wall：某行权价集中巨量未平仓合约的位置 | 识别市场共识的关键压力/支撑位，辅助判断震荡区间 |
| Max Pain 最大痛点 | 到期日股价向最大痛点收敛的历史统计倾向 | 财报周/到期周的价格磁吸参考 |
| Gamma 敞口（GEX） | 做市商对冲行为对波动率的放大/压制效应；正 GEX 压波动、负 GEX 放大波动 | 判断当前市场环境是「震荡收敛」还是「单边爆发」 |
| IV 与情绪 | 隐含波动率骤升、IV Skew 偏移、Put/Call Ratio 极值 | 识别财报/事件前的市场押注方向与恐慌程度 |

**输出规则（沿用防幻觉与合规约束）：**

- 所有期权数据标注来源与统计口径（行权价、到期日、成交/持仓量）
- 期权墙与 Max Pain 仅为**统计参考位**，明确标注「不构成价格预测」
- 财报前大额期权异动解读强制附加：「可能为投机/对冲行为，方向不代表确定性预期」
- 仅覆盖美股个股与主要 ETF；港股覆盖高流动性标的（腾讯、阿里等），A股不涉及（无个股期权）

### 模块 5：技术指标 AI 信号引擎

技术指标是散户最高频使用的分析语言，但传统软件只「画线不解读」。本模块由规则引擎自动计算指标信号，AI 负责转译为通俗语言，并做**多指标共振判定**（单指标信号噪音大，共振信号才有参考价值）。

**覆盖指标体系：**

| 类别 | 指标 | 核心信号 |
| --- | --- | --- |
| 趋势类 | MA 均线系统、MACD | 多头/空头排列、均线金叉/死叉、MACD 顶底背离 |
| 动量类 | RSI、KDJ | 超买（>70）/超卖（<30）、钝化、二次金叉 |
| 波动类 | BOLL 布林带 | 带宽收窄（变盘前兆）、突破上/下轨、中轨支撑 |
| 量能类 | 量价关系、OBV | 放量突破/缩量回调的量价配合度、量能背离 |
| 形态类 | 支撑压力位、平台/颈线 | 突破关键位、跌破平台、回踩确认 |

**信号分级机制（降噪核心设计）：**

- **一级（弱信号）**：单指标触发，仅在看板标注，不推送
- **二级（关注信号）**：2~3 个指标同向共振，纳入监控简报
- **三级（共振预警）**：技术信号 + 资金/量能/消息任一维度共振，触发推送（联动模块 6 预警系统）

**输出规则：**

- 每条信号标注指标名称、参数口径（如 MA5/MA20、RSI14）与当前数值，可溯源
- AI 转译必须通俗化：「RSI 72 且量价背离」→「短期涨幅较快、买盘力量接近极值，且资金开始不配合，追高风险上升」
- 技术信号本质为**历史统计规律**，输出强制标注「技术信号仅为参考，不构成买卖依据」；严禁输出「必涨/必跌/抄底/逃顶」类确定性表述

### 模块 6：7×24 智能预警推送系统

从「单一价格预警」升级为**逻辑化、共振式预警**。

| 预警类型 | 说明 |
| --- | --- |
| 价格阈值 | 自定义涨跌幅、突破压力/支撑位 |
| 资金共振 | 价格 + 主力资金 + 成交量三重异动 |
| 板块轮动 | 板块集体异动、高低切换、热点扩散 |
| 消息催化 | 持仓/关注赛道突发重大新闻、财报预告 |
| 期权信号（港美股） | 大额期权异动（尤其财报前）、价格逼近期权墙/最大痛点（Max Pain）、GEX 翻转 |
| 技术共振 | 多指标同向共振（如均线金叉 + 放量 + 突破平台），且与资金/量能/消息至少一个维度形成共振 |

- **推送渠道**：APP 弹窗、微信公众号/小程序、站内消息
- **推送内容**：每条预警附带 AI 简短解读 + 数据来源

### 模块 7：重点事件日历与波动预警引擎

散户「被动挨打」的重灾区：不知道 FOMC/非农是哪天、财报季 IV 会飙升、突发事件无预警。本模块构建事件驱动的波动管理体系。

**事件日历覆盖：**

| 市场 | 事件类型 |
| --- | --- |
| 美股 | CPI/大小非农、FOMC 议息、Q 财报季、月度期权到期（OpEx）、地缘/政策突发 |
| 港股 | 上述美股事件（联动传导，落地时点在亚洲盘前）、中国 CPI/PPI/社融/LPR、恒指权重股财报 |
| A股 | 中国 CPI/PPI/社融/进出口、LPR/MLF、季报披露窗口、FOMC 联动（北向与汇率渠道） |

**事件波动预警三层机制：**

1. **临近预警**（事件前 48h/24h）：推送事件定价水平（期权隐含波动、历史同类事件波动）、持仓敞口检查建议
2. **落地预警**（数据公布即时）：实际值 vs 预期对比 + 首反应结构化解读 + 影响传导链（数据 → 政策定价 → 板块）
3. **突发快讯**（7×24）：突发事件流监测，滚动更新影响评估；区分「已证实事实 / 未经证实传闻」

**输出规则：**

- 每个事件标注：类型（宏观/财报/期权/政策/联动）、重要性分级、市场预期值、期权市场隐含定价（有期权标的时）
- 财报类事件自动联动标的期权 IV（事件前 IV 飙升 = 博弈拥挤提示）
- 跨市场联动事件（如 FOMC 对港A 股的传导渠道与落地时点）单独标注

### 模块 8：每日 AI 自动复盘 Agent（核心留存功能）

收盘后自动生成个人专属复盘报告，固定模块：

1. **大盘全景**：指数走势、市场情绪、涨跌家数、赚钱效应、资金流向
2. **自选总结**：异动汇总、强弱排名、核心变化
3. **热点复盘**：主线赛道、轮动节奏、龙头标的、资金偏好
4. **风险机会**：次日潜在催化、待跟踪标的、风险点；附带**事件日历提醒**（FOMC/非农/财报/期权到期等关键节点）
5. **持仓复盘**（可选开启）：盈亏变化、持仓异动、操作优化建议

### 模块 9：投研智能问答 Agent（垂直约束）

只回答投研相关问题，禁止闲聊，输出严格受控。

- **支持场景**：个股走势/资金面/基本面极简解读、赛道逻辑与轮动分析、技术形态与量能结构通俗解读、历史行情回溯
- **强约束规则**：
  - 所有数据必须标注来源（行情接口 / 新闻原文 / 财报摘要）
  - 不确定信息直接回复「无法确认，无有效数据支撑」，**绝不编造**
  - 严禁预测涨跌、严禁荐股、严禁承诺收益
  - 所有回答结尾强制附带风险提示

### 模块 10：投研日志知识库（用户资产沉淀）

自动归档每日复盘、标的解读、预警记录；支持手动补充操作笔记，形成个人投研知识库，长期沉淀投资体系。

## 5. 核心产品规则（壁垒核心）

### 5.1 防幻觉强制规则

1. **无数据不输出**：缺少行情/新闻/资金数据时，不做主观推断
2. **结论可溯源**：每条分析绑定对应原始数据条目
3. **模糊信息强制降级**：不确定内容不做肯定式表述，全部标注风险
4. **口径强制标注**：主力资金/超大单等推算类数据标注「数据商推算口径，非真实机构持仓」；情绪评分、景气度、拥挤度等自研复合指标必须展示计算口径，杜绝黑盒分数被专业用户挑战
5. **事实/传闻分层**：市场传闻（如排产、政策消息）与已证实事实分层标注，传闻必须显式标记「未经证实」

### 5.2 金融合规强制规则

1. 无任何股票推荐、无买卖点位指导、无收益预测
2. 所有输出仅为投研信息参考与逻辑分析工具，不构成投资建议
3. 页面常驻提示：**「本产品仅提供智能投研辅助，投资有风险，决策需自主承担」**

## 6. 用户核心流程

```
注册登录 → 添加自选股/板块 → 自定义预警阈值
        ↓
7×24 自动扫描（指数结构 / 板块景气 / 个股行情 / 资金 / 新闻）
        ↓
触发异动 → AI 结构化分析 → 生成解读
        ↓
精准推送（预警 + 解读）
        ↓
收盘后自动生成复盘报告 → 归档日志
        ↓
智能问答深度答疑 → 投研认知沉淀
```

## 9. 风险与规避

| 风险类型 | 具体风险 | 规避方案 |
| --- | --- | --- |
| 合规风险 | 被判定为投顾荐股 | 全程无买卖建议、无收益预测；内容标注工具属性、强制风险提示、禁主观荐股表述 |

| 数据稳定性风险 | 行情数据延迟/缺失 | 多数据源备份、数据校验清洗、异常数据标注提示 |

## 附：MVP 落地优先级建议

| 优先级 | 模块 | 理由 |
| --- | --- | --- |
| P0 | 监控看板（含指数分析）+ 异动解读 Agent + 预警推送 | 构成核心价值闭环，验证「替用户盯盘」核心主张 |
| P1 | 板块景气引擎 + 每日复盘 Agent + 日志归档 | 自上而下链路补全 + 留存功能，形成用户资产沉淀 |
| P2 | 智能问答 Agent | 增强互动，但非核心闭环必需 |

> **建议**：MVP 期先聚焦 A 股单一市场跑通全流程，再扩展美股/港股；数据源先行接通行情 + 新闻两类，资金流与财报摘要可在 V1.1 补齐。**期权数据源**（Vol/OI、行权价分布、GEX）建议随 V1.1 美股扩展一并接入，可优先对接聚合类期权数据 API，期权墙/Max Pain 可基于期权链数据自研计算。
